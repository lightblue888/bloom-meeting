# 界面检查：第一轮复核结果（2026-11-18）

运行 `npm run test:ui`，覆盖 42 个屏幕/状态，各跑中英两种语言、4 个尺寸（1024×640 / 1280×800 / 1600×900 / 1920×1080）、深浅两种主题，共截图 800 张。机器原始报出 5954 条，合并为 138 组；人工逐组复核后剩 3 个 blocker、12 个 major、9 个 minor。
每次运行自动生成的结果在 `out/report.md` 和 `out/findings.json`（未经复核，下次运行会覆盖）。

## Blocker
- **B1** 英文界面、宽 1024 时，会议顶栏装不下，"End Meeting" / "New meeting" 被挤出窗口；人多了会更往外挤。涉及 `meeting.css` 的 `.mt-head`、`.mt-head-main`，以及 `MeetingLayout.tsx`。
- **B2** 浅色主题下，回顾页的"纪要""修改清单"文字几乎看不见（黑底上的深色字，对比度约 1.1:1）。涉及 `meeting.css` 的 `.mt-left, .mt-diff { background:#0b0b0b }`。
- **B3** 自定义模型名很长时（最多 80 字），会撑破 AI 状态条：访客页出现横向溢出，主窗口里"在听 / 在改"被挤出去。涉及 `meeting.css` 的 `.mt-now`、`.mt-now-m`。

## Major
- **M1** 头像一摞时展开的名单超出窗口，没法滚动，后面的人点不到。
- **M2** 英文 AI 卡片里，左列标签压在模型名上。
- **M3** AI 卡片里的长模型名不换行，会跑出卡片。
- **M4** 浅色主题对比度普遍不够，涉及人名颜色、灰字、主持人 / AI / 共同主持人徽章、"散会"的红字。
- **M5** 底部浮动的错误条会盖住逐字稿的最新一句。
- **M6** "上次是共同主持人 · 恢复"提示盖住逐字稿的标题行。
- **M7** 大厅里下载转写模型时，进度文字跑出"新会议"卡片。
- **M8** 大厅"缺什么"那一行高度会变，"开始会议"和"最近的会议"跟着跳。
- **M9** 头像一摞时，自己的静音角标被下一个头像盖住。
- **M10** AI 状态条第二行在任务名很长时被硬切，末尾没有省略号。
- **M11** 英文首次引导最后一步，"Transcription model" 被省略。
- **M12** 英文设置里的下拉框太窄，例如 "Xiaoxiao · Chinese female" 被省略。

## Minor
- **m1** 输入框太窄，看不全允许的最长内容。
- **m2** 英文 "Search settings" 占位文字放不下。
- **m3** 改名被拒时，报错把下面几行往下推。
- **m4** 深色主题有几处对比度偏低：时间戳、"随口"芯片、蓝色主按钮。
- **m5** 键盘和读屏：
  - 逐字稿不能用 Tab 聚焦
  - 回顾列表的 listbox 嵌套不规范
  - 模型来源的输入框没有标签
  - 下拉按钮的读屏名和看到的字不一致
- **m6** 英文出现 "1 edits so far"。
- **m7** AI 卡片和邀请弹层能同时打开，互相叠在一起。
- **m8** 浅色主题下，回顾里"整理中"的提示字对比度不够。
- **m9** 散会时顶栏的人和"邀请"会平移一次。

## 修复分工
- 会议页、访客页、回顾页（B1–B3、M1–M6、M9、M10、m4、m5 中的会议页部分、m7–m9）交给检查代理改。
- 大厅、引导、设置、文案、浏览器模拟数据（M7、M8、M11、M12、m1、m2、m3、m5 中的设置标签、m6）由主会话改。
